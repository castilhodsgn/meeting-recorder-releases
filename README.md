# MeetingRecorder — atualizações para macOS

Este repositório público contém somente os pacotes compilados e o feed de
atualizações do MeetingRecorder. O código-fonte permanece no repositório
privado e nenhuma gravação é enviada para cá.

## Instalação

Baixe a versão mais recente na pasta `releases`, descompacte o arquivo e mova
`MeetingRecorder.app` para a pasta Aplicativos.

Depois da primeira instalação da versão 0.3.0, o próprio aplicativo verifica e
instala atualizações usando o Sparkle.
